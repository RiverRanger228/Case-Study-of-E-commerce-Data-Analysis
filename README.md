# 电子产品销售数据分析
## 项目说明
项目链接：https://www.heywhale.com/mw/project/6a958925c0b84412a78556a2

基于电商平台电子产品订单明细数据的经营分析项目，覆盖数据清洗、销售趋势、区域市场、用户生命周期、客群画像与商品价格结构，并输出数据分析报告。


## 项目亮点

- 数据规模：**564,169 条**成交记录、**400,516 笔**有效订单、**93,818 名**付费用户
- 全年成交金额约 **1.17 亿元**（¥117,499,096）
- 报告按金字塔原理组织，结论先行，包含执行摘要、核心发现、详细分析、数据验证与行动建议

## 核心结论

- **销售呈强季节性**：8 月成交金额占全年 **23.8%**，约为 1-4 月合计的 **3.2 倍**；7-9 月贡献全年 52.3% 成交额
- **用户增长靠新客拉动，但留存断层**：5-8 月新增用户占 **72.1%**，到 11 月不活跃用户占 **90.8%**
- **大促未沉淀忠诚客户**：次月回购率由 2 月 **36.9%** 降至 10 月 **22.0%**
- **高价值客群明确**：40-50 岁为第一大客群；男性最高单笔成交为女性的 **1.9 倍**
- **区域机会并存**：广东、上海、北京合计贡献 **55.3%** 成交额；湖南人均消费 **1,297 元**，为各区域最高

3. **详细分析**：销售时间趋势、区域分析、用户行为与生命周期、客群画像、商品与价格结构
4. **数据验证与假设**：数据口径、关键假设与局限性

## 复现方式

环境要求：Python 3.10+，依赖 `pandas`、`numpy`、`matplotlib`、`seaborn`、`jupyter`。

```bash

```

将 `电子产品销售分析.csv` 与 `code.ipynb` 置于同一目录，启动 Jupyter Notebook 并依次运行全部单元格：

```bash
jupyter notebook code.ipynb
```

注意：`code.ipynb` 中数据读取路径为 `D:/DAproject/电商数据分析/电子产品销售分析.csv`，如目录结构变化，需同步修改读取路径。

## 数据说明与局限

- `category_code` 缺失 **129,370 条（22.9%）**、`brand` 缺失 **27,224 条（4.8%）**，分析中以 `missing` 标记
- **1,307 条** `event_time` 为 1970 年异常值（0.23%），购买间隔统计以中位数与分位数为主口径
- **3,863 名用户（4.1%）** 存在多个省份标签，区域分析以订单与成交额为主口径
- 数据覆盖 2020 年 **1-11 月**、**11 个区域**，未包含 12 月数据
